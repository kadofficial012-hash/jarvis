# jarvis
Jarvis.Ansaruddin is an advanced, modular AI assistant engineered to autonomously manage system operations, execute web tasks, and maintain persistent contextual memory. Designed with a highly extensible architecture, the agent integrates a core Large Language Model (LLM) client with local speech-to-text (STT) and text-to-speech (TTS) processing capabilities. The system operates through a unified web dashboard and main UI, allowing users to interact seamlessly while background monitors proactively handle routine background tasks.  
Core Capabilities
System & Desktop Automation: Features native computer control, screen processing, and comprehensive file management modules.  
Web & Media Integration: Includes automated browser control, YouTube video handling, and dynamic web search functionality.  
Contextual Memory: Utilizes a dedicated memory and configuration manager to maintain state and user context across operating sessions.  
Extensible Action Library: Built on a flexible plugin loader supporting custom operations, ranging from flight finding and weather reporting to specialized tasks like pushup counting.
